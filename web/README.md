# Ordering System — Web Dashboard

Giao diện web quản lý **đặt hàng nhập khẩu** (React + Tailwind + Lucide).

## Chạy

```bash
cd web
npm install
npm run dev
```

Mở http://localhost:5173

## Build production

```bash
npm run build
npm run preview
```

## Design system (60-30-10)

| Vai trò | Màu |
|--------|-----|
| 60% Nền | `#F8FAFC` |
| 30% Cấu trúc / chữ | `#1E293B` |
| 10% Accent / CTA | `#10B981` |
